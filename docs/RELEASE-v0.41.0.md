# Monsoon Dash 0.41.0 — Android Playtest

Download **Monsoon-Dash.apk** from the assets below and install on an ARM64-capable Android device running Android 7.0 / API 24 or newer. Source archives are for developers, not Android installers.

## This update

- Canal Works: new lock houses, sluice bays, copper pumps and valves, service railings, layered skyline and revised water shading.
- Cloud Gardens: planted terraces, pavilions, pergolas, hanging vines, fountains, wind leaves and warmer stone paths.
- World-specific district badges and lighting.
- Terrace Quarter and Lantern Bazaar retained; all 28 prepared scenes match the previous candidate byte for byte.

Core running, umbrella gliding, waterboard routes, missions, workshop, four playable characters, Boondi reactions, rain/settings and save progression are included.
