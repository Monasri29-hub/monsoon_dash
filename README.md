# Monsoon Dash

**Find your rhythm above the rain.**

A Godot 4.5.2 Android 3D endless runner featuring Terrace Quarter, Lantern Bazaar, Canal Works and Cloud Gardens.

The full project and Android playtest download are being uploaded. This page will be updated with screenshots, controls, setup instructions and a verified APK download when publication finishes.

## Included gameplay

Three-lane running, jumping and sliding; umbrella gliding; waterboard routes; missions and saved progression; four playable characters; cosmetic workshop; Boondi cloud-companion reactions; rain, audio and accessibility settings.

## Current build

Version **0.41.0 / code 40**, Android ARM64, API 24+. Automated regression and packaging checks passed. Physical-phone performance and final acceptance remain pending. This is a playtest build, not a Play Store release.

Project by Kundeti Monasri, developed with AI-assisted design, implementation and testing.
